# 管理后台需求规范

> 本文件供 `write-prd` Skill 第 10 步调用。当需求涉及管理后台、运营后台、配置后台或内部工作台时，根据实际角色和任务读取相关章节。

---

## 一、适用判断

满足以下任一条件时，读取本规范的相关章节：

- 存在非终端用户的操作界面（管理员、运营者、审核者、内容编辑者）。
- 需要批量管理数据、配置规则、审核内容或导出报表。
- 存在角色与权限的独立配置需求。
- 页面以列表、表单、详情、仪表盘等后台典型模式为主。

不适用范围：纯 C 端用户自助页面、仅展示不做管理操作的页面。

---

## 二、对象与权限

| 检查项 | 说明 |
|--------|------|
| 管理角色定义 | 超级管理员 / 模块管理员 / 运营编辑 / 审核员 / 只读查看者 |
| 功能权限 | 每个角色可访问哪些菜单/页面/按钮 |
| 数据权限 | 行级权限（如"仅看本支行数据"）和列级权限（敏感字段脱敏） |
| 权限授予方式 | 角色模板 / 逐人配置 / 继承上级 / 审批后生效 |
| 权限变更 | 权限被撤销时正在操作的页面如何处理 |
| 操作互斥 | 同一对象是否允许多人同时编辑 |

---

## 三、列表页规范

| 检查项 | 说明 |
|--------|------|
| 搜索与筛选 | 模糊搜索字段；多条件组合筛选；筛选条件的默认值和重置 |
| 排序 | 默认排序字段和方向；用户可切换的排序字段 |
| 分页 | 每页条数、页码跳转、总条数展示 |
| 列定义 | 每列的字段名、宽度策略、是否可排序、是否可隐藏 |
| 批量操作 | 全选/反选/跨页选择策略；批量操作的类型（删除/导出/状态变更） |
| 行操作 | 每行的操作按钮（编辑/删除/详情/审核）；操作后的页面刷新策略 |
| 空状态 | 无数据时的展示和引导（如"暂无菜品，点击新建"） |
| 加载状态 | 首次加载、翻页加载、搜索加载的 loading 方式 |

---

## 四、表单页规范

| 检查项 | 说明 |
|--------|------|
| 表单布局 | 单列/双列；分组/分步；必填标识 |
| 字段校验 | 前端实时校验 + 提交时校验；错误提示位置和样式 |
| 依赖字段 | 选项 A 影响选项 B 的可选值时的联动逻辑 |
| 默认值 | 新建时的默认值；编辑时从已有数据回填 |
| 草稿保存 | 是否支持暂存草稿；离开页面时的未保存提示 |
| 提交反馈 | 成功/失败 toast；成功后留在当前页还是跳转 |
| 重复提交 | 提交按钮置灰 + loading；后端幂等校验 |

---

## 五、详情页规范

| 检查项 | 说明 |
|--------|------|
| 信息层级 | 核心信息优先展示；次要信息折叠或分 tab |
| 关联数据 | 与当前对象关联的其他数据如何展示 |
| 操作入口 | 从详情页可触达的操作（编辑/审核/删除/返回列表） |
| 状态标签 | 对象状态的视觉标识和变化提示 |
| 操作日志 | 谁在什么时间做了什么操作（适用时） |

---

## 六、导入导出

| 检查项 | 说明 |
|--------|------|
| 导入格式 | CSV / Excel；模板下载入口 |
| 导入校验 | 逐行校验 + 错误行提示；全量失败还是部分成功 |
| 导入上限 | 单次导入的最大行数 |
| 导出格式 | Excel / CSV / PDF |
| 导出范围 | 当前页 / 全部 / 勾选项 |
| 导出字段 | 是否与列表展示字段一致；是否需要额外字段 |
| 异步导出 | 大数据量时是否需要异步生成 + 下载链接通知 |

---

## 七、审核与工作流

| 检查项 | 说明 |
|--------|------|
| 审核触发 | 什么操作触发审核（提交/发布/修改）；自动触发还是手动发起 |
| 审核角色 | 谁可以审核；是否支持多级审核 |
| 审核操作 | 通过/驳回/转审；驳回时是否必须填写原因 |
| 审核通知 | 审核任务的通知方式和入口 |
| 状态流转 | 待审核 → 审核中 → 已通过/已驳回，每个状态的可操作项 |
| 撤回 | 提交者在审核前是否可以撤回修改 |
| 审核日志 | 审核记录的可追溯性 |

---

## 八、仪表盘与统计

| 检查项 | 说明 |
|--------|------|
| 统计维度 | 时间/地域/角色/状态等维度的统计 |
| 图表类型 | 折线图/柱状图/饼图/雷达图的选择依据 |
| 实时性 | 实时/准实时/T+1；数据刷新频率 |
| 下钻能力 | 从汇总数据点击进入明细列表 |
| 导出 | 统计图表的数据导出 |

---

## 九、通用体验

| 检查项 | 说明 |
|--------|------|
| 操作确认 | 删除/下架/批量操作等不可逆操作的二次确认弹窗 |
| 操作反馈 | 操作结果的即时反馈（成功/失败/处理中） |
| 错误处理 | 网络错误、超时、权限不足的提示和恢复方式 |
| 响应式 | 后台是否需要适配移动端或平板 |
| 性能感知 | 大数据量列表的加载策略（虚拟滚动/分页） |

---

> 以上为管理后台需求的通用检查维度。具体产品按需选取，不要求逐条覆盖。
