# 接口需求模板

> 本文件供 `define-interface-requirement` Skill 第 7 步"定义单接口业务契约"调用。为每个接口/数据交换场景填写以下内容。

---

## 接口业务契约

### 基本信息

| 字段 | 内容 |
|------|------|
| 接口编号 | IF-XXX（稳定编号，不随版本变化） |
| 业务名称 | 使用业务语言描述（如"提交菜品发布记录"） |
| 所属流程 | 对应哪个业务流程节点 |
| 场景类型 | 我方主动推送 / 对方主动获取 / 我方被动接收 / 我方主动获取 |
| 提供方 | 系统名称 + 责任团队 |
| 使用方 | 系统名称 + 责任团队 |
| 版本 | V1.0 |
| 状态 | 草案 / 待确认 / 已确认 / 已上线 / 已废弃 |

### 业务目的与场景

- **为什么要做这个接口**（业务目的，不是技术目的）
- **在什么业务场景下触发**
- **触发事件和前置条件**
- **调用频率预估**（如"每人每日 1 次""高峰期 500 次/分钟"）

### 发起方与触发

| 字段 | 内容 |
|------|------|
| 发起方 | 哪个系统/角色发起 |
| 触发节点 | 用户操作 / 定时任务 / 事件回调 / 状态变更 |
| 前置条件 | 发起前必须满足的业务条件 |
| 调用约束 | 频率限制、并发限制、调用窗口 |

### 请求/推送的业务对象

- **传递什么业务对象**（如"菜品发布记录"）
- **该对象在提供方系统中的权威来源**

### 业务输入

| 字段名 | 业务含义 | 类型 | 必填 | 来源 | 枚举/范围 | 空值含义 | 敏感级别 |
|--------|----------|------|:---:|------|-----------|----------|:--:|
| | | | | | | | |

> 产品经理使用业务字段名，技术字段名由研发在接口技术文档中映射。

### 业务输出（返回/回执）

| 字段名 | 业务含义 | 类型 | 必返回 | 说明 |
|--------|----------|------|:-----:|------|
| | | | | |

### 成功后的业务结果

- **使用方收到成功响应后，业务上会发生什么变化**
- **用户会看到什么反馈**
- **数据状态如何变化**

### 失败后的业务行为

| 失败类型 | 触发条件 | 提供方行为 | 使用方行为 | 用户反馈 |
|----------|----------|------------|------------|----------|
| 业务拒绝 | 如"菜品已在该日期发布" | 返回业务错误码 + 原因 | 展示提示，允许修改后重试 | toast + 原因说明 |
| 系统超时 | 超过 X 秒无响应 | — | 重试 N 次后降级 | toast"网络繁忙" |
| 服务不可用 | 提供方宕机 | — | 进入降级模式 | 提示 + 稍后再试入口 |
| 数据校验失败 | 如必填字段为空 | 返回校验错误列表 | 逐字段标红 | 表单校验提示 |

### 重复与并发

- **幂等键**：用什么字段保证不重复处理
- **重复请求的业务结果**：幂等返回上一次结果 / 拒绝 / 覆盖
- **并发写同一对象的业务行为**
- **消息乱序/迟到/丢失的处理策略**

### 状态映射

若涉及跨系统状态：

| 本方状态 | 对方状态 | 映射关系 | 不一致时的处理 |
|----------|----------|:--:|--------------|
| | | 1:1 / 1:N | 以谁为准 |

### 时效与同步

| 维度 | 要求 |
|------|------|
| 同步时效 | 实时 / 准实时（≤X秒）/ 异步 / 定时 |
| 同步方式 | 全量 / 增量 / 按条件 |
| 用户是否需要等待 | 是 / 否（异步通知结果） |
| 数据延迟容忍度 | 最多 X 秒/分钟 |

### 安全与权限

| 维度 | 要求 |
|------|------|
| 调用认证 | 系统级认证方式 |
| 用户授权 | 是否需要终端用户授权 |
| 传输加密 | HTTPS 必须 |
| 敏感字段 | 哪些字段需要加密传输/脱敏存储 |
| 审计要求 | 是否记录操作日志；日志保留时长 |

### 非功能要求

| 维度 | 要求 |
|------|------|
| 响应时限 | P95 ≤ X ms |
| 并发上限 | 支持 X QPS |
| 批量上限 | 单次最多 X 条 |
| 可用性 | 99.X% |
| 限流策略 | 超限后的返回和提示 |

### 联调验收

| 场景编号 | 验收场景 | 预期结果 | 验收状态 |
|:--:|------|------|:--:|
| IF-XXX-01 | 正常请求 | 返回成功 + 业务数据正确 | |
| IF-XXX-02 | 必填字段缺失 | 返回校验错误，不写入数据 | |
| IF-XXX-03 | 重复请求 | 幂等返回 | |
| IF-XXX-04 | 超时场景 | 按失败策略处理 | |
| IF-XXX-05 | 权限不足 | 返回 403 | |

### 变更记录

| 版本 | 日期 | 变更内容 | 是否向后兼容 | 责任人 |
|------|------|----------|:--:|------|
| V1.0 | | 初始版本 | — | |

---

> 本模板用于单接口业务契约。简单接口可精简填写，复杂接口、跨组织接口建议逐项确认。
